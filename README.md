# Weather Data Analysis

## About the Project
This project performs weather data analysis using Python and popular libraries such as NumPy, Pandas, and Matplotlib. NumPy is used for statistical calculations, Pandas for data handling, and Matplotlib for data visualization.
## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Weather data visualization
- Average temperature calculation
- Maximum and minimum temperature
- Average humidity calculation
- Total rainfall calculation
- Temperature trend analysis

## Project Files
- Weather_analysis.py – Python source code
- weather.csv – Weather dataset

## How to Run
1. Install Python.
2. Install required libraries:
   pip install numpy pandas matplotlib
3. Run Weather_analysis.py.

## Learning Purpose
This project is useful for practising Python
and basic data analysis concepts.
